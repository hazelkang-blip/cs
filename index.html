사용방법

세금계산서 취소 문의가 들어오면 단계별로 진단해 답변 스크립트를 받거나 기획자 이관 여부를 판정하는 도구입니다.

0. 시작 전 · 응대 모드 선택

!
응대 모드 선택 실제 고객 응대는 실제 응대 모드(파란 헤더), 연습은 테스트 모드(주황 헤더)로 둡니다. 테스트로 확정한 기록은 실제 통계에서 제외됩니다.

1. 진단 · 응대 (3단계)

1
결제 정보 입력 결제일, 서비스 시작일, 문의 접수일을 입력하고 [다음]을 누릅니다. 결제일과 서비스 시작일이 같으면 [결제일과 동일] 버튼으로 자동 입력됩니다. 입력하면 환불 조건과 세금계산서 상태가 자동 계산되어 미리 표시됩니다.
2
문의 유형 선택 먼저 카드 결제 증빙 중복 우려 문의인지 확인합니다. 맞으면 1차 안내 스크립트가 표시되고, 안내 후에도 취소를 원하는지에 따라 종결 또는 상세 진행으로 나뉩니다. 그 외 취소 요청이면 [아니오]를 선택하고 [다음]을 누릅니다. 이 경우 답변은 환불 여부와 세금계산서 발행 상태에 따라 달라집니다.
3
상태 확인 환불 여부(전액/부분)는 문의 접수일 기준으로 자동 확정되어 회색으로 표시됩니다(선택 불필요). 부분환불이면 환불 예정 금액도 함께 나옵니다. 세금계산서 발행 상태를 직접 선택하고, 발행 전·마감 전이면 결제 취소 여부까지 선택한 뒤 [결과 보기]를 누릅니다.

2. 결과 화면 활용

  • 상단 판정 배너로 처리 방향을 확인합니다. 초록은 CS 답변으로 종결, 주황은 기획자 이관 필요입니다.
  • 내부 대응 지침(담당자용)과 고객 발송용 스크립트가 구분되어 나옵니다. 스크립트는 [스크립트 복사]로 바로 사용합니다. (가이드에 없던 답변은 ‘가이드 기반 생성본’으로 표시됩니다.)
  • 이관이 필요하면 고객 안내 → 서류·정보 확보 → 기획자 이관 순서로 진행하고, [이관 요약 복사] 또는 [결과 공유 링크 복사]로 전달합니다.

3. 응답 기록

✓
사용 확정 / 취소 실제로 사용한 답변은 [이 답변 사용 확정]을 눌러 통계에 반영합니다. 잘못 눌렀다면 [확정 취소]로 되돌릴 수 있습니다.

4. 통계 대시보드

  • 실제 응대 총건은 이관 건과 CS 답변 종결 건의 합으로 집계됩니다. 확정한 건만 집계되며, 이관과 종결은 진단 결과로 자동 분류됩니다.
  • 공용 DB를 연결하면 여러 담당자의 기록이 실시간으로 합산되고, [CSV 내보내기]로 다운로드할 수 있습니다.

5. 환불 금액표 · 가이드 원문

  • 환불 금액표 탭에서 서비스 사용일수별 최종 취소/환불 금액(34,900원 기준)을 확인할 수 있습니다. 진단에 날짜를 입력했다면 현재 케이스의 사용일차가 강조됩니다.
  • 가이드 원문 탭의 목차 항목을 누르면 해당 위치로 바로 이동합니다.
Tip. 카드 증빙중복 문의가 아니어도 날짜와 발행 상태에 따라 답변이 달라집니다. 결제일과 서비스 시작일을 먼저 입력한 뒤 진단하세요.
